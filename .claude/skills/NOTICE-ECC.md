# Origem de parte destas skills

As skills `acessibilidade`, `i18n-sync`, `supabase-banco` (junção de `postgres-patterns` e
`database-migrations`) e `seguranca-lumi` (de `security-review`) foram **reescritas para o Lumi** a partir de
skills do projeto ECC (https://github.com/affaan-m/ECC, versão 2.2.3), licenciado sob MIT. Foram mantidas
as ideias e as listas de verificação que servem a um app Expo/React Native + Supabase; o resto (web, SwiftUI,
Compose, Prisma, Solana, CSRF etc.) ficou de fora. `postgres-patterns` cita como base as Supabase Agent
Skills (também MIT).
